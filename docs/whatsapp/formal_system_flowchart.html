Poornasree AI — Formal Professional Flowchart Architecture

Standard System Decision Tree Diagram (ISO Corporate Format)

START: Customer Sends WhatsApp Message
1. Webhook Payload Ingestion & Heartbeat
whatsapp.controller.ts
System receives WhatsApp JSON webhook payload. Sanitizes string input (upper = text.toUpperCase().trim()) and starts background 2s periodic typing indicator loop.
2. Is Language Switch Requested?
Checks if customer typed language command ("Malayalam", "Hindi me bolo", "Tamil") or tapped [Select Language] button.
YES (Language Request)
Save Language Preference
PostgreSQL Session
Saves meta.language (ML/HI/TA/KN/TE/MR/BN/EN) in DB. All future greetings, steps & buttons auto-translate into requested language.
Chat Continues in Target Language
NO (Standard Input)
3. Database Identity Check
Prisma Query
Queries PostgreSQL User table by WhatsApp phone number to check if customer is registered in system.
4. Is Customer Registered in Database?
Evaluates User entity existence for current phone number.
NO (New Customer)
Registration Prompt & 5-Step FSM
simulate.service.ts
Sends Registration Prompt: [📝 Register Machine], [⏭️ Skip for Now], [🌐 Select Language].
If customer registers: Guides through Serial ➔ Name ➔ Pincode ➔ Location. Saves user in DB.
YES (Registered)
Welcome Back Greeting
whatsapp-agent.service.ts
Sends Welcome Back greeting with full options:
[🛠️ Book Service] [📝 Register Machine] [🌐 Change Language]
5. Is Intent a Hardware Complaint?
Checks if message contains technical symptoms (error, vibro, power, temp, reading, sample).
NO (Sales / FAQ)
Product & Photo Dispatcher
Product DB
Dispatches model specifications, brochure PDFs, and head office photos.
Session Completed
YES (Hardware Fault)
Candidate Prefilter Engine
complaint-classifier.service.ts
Scores 200+ DocumentIssue entries from CHATBOT_DATAS. Applies short-term keyword boosts (+25 pts) for T2, Vibro, Power, Sensor. Returns top 15 candidates.
6. Groq 70B Semantic Classification
llama-3.3-70b-versatile
Evaluates user query against prefiltered candidates using Groq 70B model. Requires minimum confidence threshold score of 75+.
7. Training Document Match Found (Score >= 75)?
Verifies if query matches an authoritative DocumentIssue entry from CHATBOT_DATAS.
YES (Match Found)
Output Checks & Actions
CHATBOT_DATAS Row
Outputs exact Check & Action steps from DocumentIssue + auto-recommends YouTube video guide.
Buttons: [✅ Yes, Resolved] [🛠️ Register Complaint] [💬 Talk to us]
Issue Resolved (Session Ended)
NO (Unlisted Fault)
Strict Escalation Notice
Strict Rule
Enforces Strict Non-Hallucination Rule:
"We don't have a self-troubleshooting guide for this specific issue in our training documents. 🙏 Please tap Register Complaint below..."
Buttons: [🛠️ Register Complaint] [💬 Talk to us]
Service Ticket & Field Alert
ticket.service.ts
Captures 10-digit Machine Serial Number ➔ Writes Service Ticket in DB ➔ Dispatches real-time WhatsApp & Push notifications to Field Engineers.
Ticket Logged & Field Visit Assigned
