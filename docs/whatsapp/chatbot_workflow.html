Poornasree AI Chatbot Architecture

WhatsApp Self-Troubleshooting & Complaint Escalation Engine

Live Production Engine
Stage 1: Ingestion & Session Boot
1. Incoming WhatsApp Message
STEP 01

Receives incoming text/media payload via WhatsApp Business API webhook. Starts background typing animation heartbeat loop (2s periodic interval).

Text Payload
Extracts text message string, trims whitespace, and converts to uppercase for intent checks.
Typing Indicator
Sends continuous typing indicator state to user's WhatsApp mobile client.
Stage 2: Multi-Language & Registration Context
2. Language Persistence & Registration Routing
STEP 02

Intercepts explicit language commands (English, Hindi, Malayalam, Tamil, Kannada, Telugu, Marathi, Bengali) and checks user registration status in PostgreSQL database.

Registered User
Greets with personalized buttons: [Book Service], [Register Machine], [Change Language].
Unregistered User
Shows registration prompt: [Register Machine], [Skip for Now], [Select Language].
Language Persistence
Saves meta.language in DB. All future responses & buttons auto-translate to target language.
Stage 3: Training Document Classification
3. Groq 70B Hybrid Catalog Classifier
STEP 03

Evaluates input against 200+ DocumentIssue records from CHATBOT_DATAS excel sheet. Uses short-term boosts for T2, Vibro, Power, Sensor, and Temp Set.

Candidate Prefilter
Scores catalog entries based on product keywords and word boundary aliases (e.g. T2, No T2, Vibro).
Groq 70B Inference
Invokes llama-3.3-70b-versatile agent model with prompt strictness. Score threshold 75+ required.
Stage 4: Resolution or Strict Escalation Branching
4. Strict Non-Hallucination Response Engine
STEP 04

Enforces strict compliance with training document. Never invents fake hardware troubleshooting steps.

Match Found (Score >= 75)
Returns exact Check & Action steps from DocumentIssue. Translates text & suggests YouTube video.
No Match / Unlisted Issue
Outputs escalation notice: "We don't have a self-troubleshooting guide for this specific issue..." + [Register Complaint] button.
Stage 5: Service Ticket & Field Engineer Dispatch
5. Complaint Booking & Real-Time Notification
STEP 05

Collects 10-digit Machine Serial Number, logs service complaint ticket in PostgreSQL, and dispatches real-time WhatsApp & Push notifications to Admin & Field Engineers.
