Customer & Chatbot Complete Flowchart

Poornasree AI Customer Journey & Dialogue State Architecture

STAGE 01

Entry & Customer Identity Check

1. Initial WhatsApp Contact
Customer initiates contact via WhatsApp message
Customer Behavior
Sends greeting ("Hi", "Namaste", "Menu") or directly types issue/question ("no t2 error", "vibro nahi chal raha", "Malayalam").
Chatbot System Action
1. Starts periodic 2s typing animation heartbeat.
2. Searches User table by WhatsApp phone number.
Unregistered Customer Path
Bot shows Welcome & Registration prompt:
[📝 Register Machine] [⏭️ Skip for Now] [🌐 Select Language]
Registered Customer Path
Bot welcomes back registered customer:
[🛠️ Book Service] [📝 Register Machine] [🌐 Select Language]
STAGE 02

Language Switch & Intent Routing

2. Dialogue Intent & Multi-Language Router
Evaluates message type and user language preferences
A. Language Switch Requested
User says "Malayalam", "Hindi", "Tamil" or taps [Select Language].
Saves meta.language in DB. All future responses, steps & buttons translate to that language.
B. Product / Sales Inquiry
User asks "Lactosure price", "company address", "send brochure".
Bot dispatches active product specs, catalog images & company photos.
C. Hardware Complaint / Fault
User types fault ("t2 error", "vibro slow", "reading variation").
Routes to Groq 70B Hybrid Classifier.
STAGE 03

Groq 70B Classifier & Training Document Verification

3. Self-Troubleshooting vs Strict Escalation Branch
Evaluates complaint against 200+ DocumentIssue entries from CHATBOT_DATAS
Match Found (Confidence >= 75)
Bot outputs exact Check & Action steps from DocumentIssue:
1. Check: Leakage/Block -> Action: Silicon Tube
2. Check: L-Plug -> Action: O-Ring

Translates steps to user's active language & suggests YouTube video.
Buttons: [✅ Yes, Resolved] [🛠️ Register Complaint]
Unlisted Issue / No Document Match
Bot enforces Strict Non-Hallucination Rule:
"We don't have a self-troubleshooting guide for this specific issue in our training documents. 🙏 Please tap Register Complaint below..."

Buttons: [🛠️ Register Complaint] [💬 Talk to us]
STAGE 04

Service Complaint Ticket & Field Dispatch

4. Service Booking & Real-Time Notification
Logs complaint ticket and alerts field engineers
Customer Action
Customer taps [🛠️ Register Complaint] -> Enters 10-digit Machine Serial Number (e.g. ECO-2024-8841).
System Action
1. Creates Service Ticket record in PostgreSQL DB.
2. Dispatches instant WhatsApp & Push notifications to Admin & Field Engineer.
3. Sends confirmation & ticket ID to customer.
