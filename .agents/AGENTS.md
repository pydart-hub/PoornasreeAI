# Workspace Agent Rules

## MANDATORY PRE-IMPLEMENTATION PLANNING RULE
For every command, request, or feature proposed by the user:
1. **Study First**: Research the codebase, database schema, APIs, and data requirements thoroughly before taking any action.
2. **Build & Present Implementation Plan**: Create or update the `implementation_plan.md` artifact detailing exact file changes, component architecture, data models, and verification steps.
3. **Obtain Approval Before Implementation**: Present the plan to the user and wait for explicit user confirmation/command BEFORE executing any code modifications, database edits, or deployment scripts.

## AUTOMATIC SKILL & STACK ENFORCEMENT DIRECTIVE
For every user request:
- **UI/UX & Web Features**: Automatically activate `building-data-apps` skill principles (high aesthetics, glassmorphism, responsive Tailwind, micro-animations, type-safe Next.js components).
- **AI & Multimodal Operations**: Automatically activate `gemini-interactions-api` and `gemini-live-api-dev` skill principles (dual LLM failover, structured JSON outputs, streaming chat, voice transcription).
- **Database Safety**: Automatically apply `accidental-data-loss-prevention` rules before running schema mutations or migrations.
